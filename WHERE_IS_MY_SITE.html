Where your website link lives, and what it looks like

Your site's link does not appear on your repository's main page — GitHub keeps it in one specific place. Here is exactly where, and how to tell the difference between "live" and "not ready yet".

Settings is the last tab across the top of your repository. Pages is in the left-hand menu.

2This green box is your link — this is what LIVE looks like

GitHub Pages
✅ Your site is live at https://maria-lopez.github.io/llm-cost-calculator/ Visit site

The green box sits at the very top of the Pages screen. Visit site opens your calculator; the written address is the link you copy and share. If you see this box, you are done — everything below it on that screen can be ignored.

Green box with "Your site is live at" = your website is working

3Reading the address

The address always has the same three parts, so you can also just type it from memory:

https://maria-lopez.github.io/llm-cost-calculator/
■ your username — shown top-left of your repository, before the slash ■ github.io — the same for everyone ■ the repository name — what you called the folder
A common mix-up: github.com/maria-lopez/llm-cost-calculator is where the files live. Your website is the github.io address. Share the github.io one.

The address bar shows the github.io address with a padlock. As people change answers, the address quietly grows longer — that's normal, and it means copying the address bar shares that exact estimate, not just the blank calculator.

5And this is what NOT-READY looks like

maria-lopez.github.io/llm-cost-calculator/
404There isn't a GitHub Pages site here.

Seeing this in the first couple of minutes after saving the Pages settings is completely normal — the first build is slow. Wait two minutes, refresh. If it is still there after ten minutes: go back to Settings → Pages and check the settings read Deploy from a branch · main · / (root), and check your file is named exactly index.html.

These are simplified drawings — GitHub changes small details of its design now and then, but the Pages screen and the green "live at" box keep their place. Print this page (Ctrl-P or Cmd-P) for a paper copy.
