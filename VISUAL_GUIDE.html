Commit changes
The website only works if the first file is named exactly index.html. If your computer renamed it — to index (1).html, say — rename it back before uploading. And do not upload the Excel workbook: the repository is public, and the workbook is meant to be requested from Mark, not downloaded.

When the file names appear in the list, scroll down and click Commit changes
